# Quiz Creator

This is a standalone Next.js app for creating and viewing multiple-choice quiz
questions. It saves records in Firebase Realtime Database under
`quizQuestions`.

## Run locally

1. Copy `.env.example` to `.env.local` and enter the Firebase values used by
   your project.
2. From this folder, install dependencies and start the app:

   ```powershell
   npm install
   npm run dev
   ```

3. Open http://localhost:3001.
